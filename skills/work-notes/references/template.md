## Opportunity page
Properties: `Opportunity Name` = `<Account> - <New Client | use case>`, `Activity Level`, `📁 Account`, `🧑‍🤝‍🧑 People`.

```
## 📌 Deal brief (AI-maintained · last update YYYY-MM-DD)

### Snapshot
- What: <company, industry, one line>. Use case: <…>.
- Stage: <discovery / demo / POC / proposal / negotiation / closed>. Activity: <property value>.
- Last contact: <date, what>. Next step: <what, owner, date>.

### People
- <Name> — <title> · <role in the deal: champion / economic buyer / technical evaluator / blocker / user> · <stance>
- UnifyApps: <AE>, <SA>, <others> (linked in People)

### Numbers
- <figure> — <source, date> — <client figure | our model | validated>

### Solution
- Pain and goal in 2 lines.
- What we propose / built (in the UnifyApps platform), phases, integrations.

### Decisions
- YYYY-MM-DD — <decision> (<who>)

### Open questions & risks
- <question> — <owner>

### Next steps
- [ ] <action> — <owner> — <date>

### Assets
- Deck / demo / POC doc / CEP workbook / configuration guide / explainer: <link or Drive file name>
```
